AceAroSpace Website

HOW TO OPEN
1. Extract this ZIP file.
2. Open the extracted AceAroSpace_Website_AceAroSpace folder in VS Code.
3. Open index.html and use Live Server, or open index.html in your browser.

EDITING
- HTML pages are formatted vertically with readable indentation.
- Shared styling is in assets/css/main.css.
- Shared navigation behavior is in assets/js/main.js.
- Supplied illustrations and flag-inspired images are in assets/img/.

PAGES
index.html: Home
category.html: Learn
blog-details.html: Stories (includes public Ace/Aro figures and supplied illustrations)
author-profile.html: Community
contact.html: Resources
about.html: About
search-results.html: Search
starter-page.html: You Belong Here

Note: Google Fonts and Bootstrap Icons use internet CDNs.
